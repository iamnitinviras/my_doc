# Your First Project

Nemo enim ipsam voluptatem quia voluptas sit aspernatur aut odit aut fugit.

## 1. Create the project

```bash
demo init hello-world
```

## 2. Add a page

```bash
demo add page about
```

## 3. Preview it

```bash
demo serve
```

Open `http://localhost:3000` in your browser.

{% hint style="success" %}
That's it — your first project is running.
