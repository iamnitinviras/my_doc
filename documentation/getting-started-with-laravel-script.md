# Getting started with Laravel Script

Laravel Script sells ready-made code scripts built on the Laravel PHP framework. This page introduces the product and walks you through the first steps: finding a script, getting it, and deciding whether it fits your project. For installation details, see [Installing a script](#), and for usage rights, see [License and usage terms](#).

## What Laravel Script offers

Laravel Script is a collection of code scripts offered through the website [laravelscripts.net](https://laravelscripts.net/). Each script is written for Laravel, so it is designed to run alongside the framework's conventions for routing, controllers, and configuration.

Because scripts are sold as code, you receive source files you can read, adapt, and extend. Review the script's description on its product page before you buy to confirm it matches what you need.

## Before you begin

Check the following before you buy or install a script:

- **Laravel and PHP versions.** Confirm which Laravel and PHP versions the script supports. Your project's versions must match.
- **Server requirements.** Make sure your hosting environment meets the script's requirements, such as PHP extensions and a database if the script uses one.
- **Project fit.** Read the script's feature list and check that it covers your use case.

{% hint style="warning" %}
Needs verification: The Laravel and PHP versions each script supports, and any other server requirements.
{% endhint %}

## Finding a script

1. Go to [laravelscripts.net](https://laravelscripts.net/).
2. Browse the available scripts and open the product page for the one you want.
3. Read the description, supported versions, and any included documentation.
4. Complete the purchase using the steps shown on the site.

## Getting your script

After purchase, you receive your script. The delivery method determines how you access the files.
