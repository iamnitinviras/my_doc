# License and usage terms

This page explains, in general terms, how you may use a Laravel Script after you buy it. It is not a replacement for the full license agreement, and the exact terms must be confirmed before you rely on them.

## Summary

Laravel Script sells Laravel code through [https://laravelscripts.net/](https://laravelscripts.net/). Each purchase gives you the right to use the script under the license that applies to that product. The license is the authoritative source for what you can and cannot do.

{% hint style="warning" %}
Needs verification: The license type (for example, a named open-source license or a proprietary commercial license) and its full text, as reviewed by the legal owner. Link the full license text here once it is confirmed.
{% endhint %}

## What the license covers

Confirm the following for each product before publishing:

- Whether one purchase covers a single project or multiple projects.
- Whether you may use the script in personal projects.
- Whether you may use the script in client projects, including work you deliver to someone else.

{% hint style="warning" %}
Needs verification: The number of projects covered by one purchase, and whether client work is permitted under the license.
{% endhint %}

## Modifying the code

Many buyers adapt scripts to fit their own needs. Check the license for:

- Whether you may modify the code.
- Whether modified versions may be used in production.
- Whether you must keep original copyright or license notices in the code.

{% hint style="warning" %}
Needs verification: The rules on modifying the code and keeping copyright or license notices.
{% endhint %}

## Redistribution and resale

Redistribution covers sharing, reselling, or publishing the code, including modified versions. Unless the license says otherwise, assume the following are not permitted without written permission:

- Selling the script or copies of it.
- Sharing the code with people who have not purchased a license.
- Publishing the code in public repositories, template marketplaces, or download sites.

{% hint style="warning" %}
Needs verification: The exact rules on reselling, sharing, and publishing modified code, and whether any exceptions apply.
{% endhint %}

## Refunds and updates

Usage rights may be tied to refund and update policies. For example, a refund may end your license, and updates may be available only during a set period.

{% hint style="warning" %}
Needs verification: The refund policy, the update policy, and whether either one affects usage rights.
{% endhint %}

## Questions about your license

If your planned use is not clearly covered by the license, contact the Laravel Script team before you start the project. Do not assume that a use is allowed.

{% hint style="info" %}
Keep a copy of your purchase receipt and the license file that came with your download. You may need them to show what you bought.
{% endhint %}
